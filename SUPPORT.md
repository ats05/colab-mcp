# Support

For reproducible problems specific to this fork, open a GitHub issue and include
the operating system, Python and `uv` versions, MCP client, transport, command
arguments with secrets removed, and relevant redacted logs.

Do not post token-bearing Colab URLs, OAuth files, refresh tokens, private
notebook contents, or other credentials. Use the private reporting process in
SECURITY.md for vulnerabilities.

Questions about the official project should be directed to the official
[`googlecolab/colab-mcp`](https://github.com/googlecolab/colab-mcp) project.
Support for this community fork is best-effort and has no guaranteed response
time.
