# Contributions

This is a private standalone mirror focused on reliable Claude Code and Codex
handoff for Google Colab. It is based on the upstream project but is maintained
separately; external contributions are not currently being accepted.

For problems specific to this repository, open an issue in
[`ats05/colab-mcp`](https://github.com/ats05/colab-mcp/issues). For upstream
Colab MCP questions, use the official
[`googlecolab/colab-mcp` discussions](https://github.com/googlecolab/colab-mcp/discussions).
